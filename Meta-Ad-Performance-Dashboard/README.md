# 📢 Meta Ad Performance Analytics Dashboard

Developed an interactive Meta Ad Performance Dashboard in Microsoft Power BI using datasets including Users, Campaigns, Ads, Ad Events, and a custom Calendar Table to analyze advertising performance, engagement trends, and campaign effectiveness.

Implemented advanced DAX calculations, KPI analysis, dynamic parameter-based visual switching, and interactive slicers for deeper campaign insights.

## 📊 Key Features
- KPIs:
1. Impressions
2. Clicks
3. Shares
4. Engagements
5. Comments
6. Purchases
7. Total Budget
8. Average Budget
9. Conversion Rate
10. Click Through Rate (CTR)
11. Purchase Rate
-  Interactive analytics using:
1. Dynamic parameter-driven trend analysis
2. Dynamic chart titles using SELECTEDVALUE()
3. Weekly trend analysis
4. Gender, Country, Hour & Age-based filtering
- Calendar tooltip trend insights
## 📈 Visualizations Used
1. Dynamic KPI Trend Charts
2. Matrix Analysis by Ad Type & Engagements
3. Country-wise Engagement Analysis
4. Interactive Tables & Trend Visuals
- Dynamic Slicer-based Reporting
