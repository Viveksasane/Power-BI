# 📢 Marketing Campaign Analysis Dashboard

Developed an interactive Marketing Campaign Analysis Dashboard in Microsoft Power BI to analyze campaign performance, engagement trends, acquisition costs, and marketing ROI using campaign datasets with metrics like impressions, clicks, engagement score, conversion rate, ROI, and acquisition cost.

Implemented a star-schema data model with advanced DAX calculations, MoM analysis, KPI indicators, hierarchy drill-down reporting, and interactive slicers for Month, Location, and Language.

## 📊 Key Features
- KPIs:
1. Total Impressions
2. Total Clicks
3. Total Acquisition Cost
4. Total Engagement Score
5. MoM Growth Analysis
## 📈 Visualizations:
1. Company-wise Spend Analysis
2. Platform-wise Impressions
3. Funnel Chart for Click Analysis
4. Engagement Score by Age Groups
5. Geographic Campaign Analysis using Maps
6. Hierarchy Matrix for multi-level campaign drill-down
