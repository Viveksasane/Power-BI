# 👨‍💼 HR Analytics & Employee Attrition Dashboard

Developed an interactive HR Analytics Dashboard in Microsoft Power BI to analyze employee attrition, workforce demographics, job satisfaction, and departmental performance using HR employee datasets.

Implemented advanced DAX calculations, KPI analysis, interactive slicers, and employee segmentation techniques to identify attrition trends and workforce insights.

## 📊 Key Features
- KPIs:
1. Overall Employees
2. Active Employees
3. Attrition Count
4. Attrition Rate
5. Average Employee Age
- Employee & Attrition Analysis:
1. Department-wise Attrition Analysis
2. Employees by Age Group
3. Job Satisfaction by Job Role
4. Attrition by Education Field & Gender
5. Department-wise Monthly Income
6. Business Travel Analysis by Department
## 📈 Visualizations Used
1. KPI Cards
2. Donut Charts
3. Bar Charts
4. Tables
5. Department-wise Comparative Visuals
6. Employee Demographic Analysis
