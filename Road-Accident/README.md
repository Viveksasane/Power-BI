# 🚗 Road Accident Analysis Dashboard

Developed an interactive Road Accident Analysis Dashboard in Microsoft Power BI to analyze accident severity, casualty trends, road conditions, and location-based accident insights using road accident datasets.

Implemented advanced DAX calculations, KPI analysis, time intelligence functions, and interactive reporting to identify accident patterns and casualty trends across different vehicle types, road conditions, and environments.

## 📊 Key Features
- KPIs:
1. CY Casualties
2. CY Accidents
3. CY Fatal Casualties
4. CY Serious Casualties
5. CY Slight Casualties
-  Accident & Casualty Analysis:
1. Casualties by Vehicle Type
2. CY vs PY Monthly Casualty Trends
3. Urban vs Rural Casualty Analysis
4. Casualties by Road Type
5. Casualties by Light Conditions
6. Location-based Accident Analysis
## 📈 Visualizations Used
1. KPI Cards
2. Line Charts
3. Bar Charts
4. Donut Charts
5. Maps
6. Trend Analysis Visuals
7. Comparative Yearly Analysis
