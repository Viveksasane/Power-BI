# 📶 Telecom Customer Analytics & Network Performance Dashboard

Developed an interactive Telecom Analytics Dashboard in Microsoft Power BI using datasets including Customers, Bills, Data Usage, Call Records, Complaints, Plans, Payments, SMS, Towers, Geography, and a custom Date Table to analyze customer behavior, revenue trends, network performance, and churn insights.

Implemented a star-schema data model with advanced DAX calculations, YoY time intelligence analysis, KPI tracking, and interactive slicers for dynamic reporting.

## 📊 Key Features
- KPIs:
1. Total Customers
2. Total Revenue Amount
3. Average Revenue Per User (ARPU)
4. Collection Efficiency
5. YoY, CY & LY Growth Analysis
- Customer & Revenue Analysis:
1. Customers by Plan Type & Loyalty Level
2. Top 7 Customers by Revenue
3. Revenue Trend Analysis
4. Churn Proxy Customer Analysis
5. Network & Usage Analytics:
6. Total Towers, Operators & Status by State
7. Data Usage Analysis by State & Type
8. Average Call Duration Trends
9. SMS Analysis by Message Type
- Complaint & Churn Insights:
1. Complaints vs Last Year Complaints by Issue Type
2. Complaints by City & Tower
3. Churn Proxy Analysis by State, Gender & Loyalty Level
## 📈 Visualizations Used
